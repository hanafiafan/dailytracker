DAILY TASK — PAKET MIGRASI DATABASE
Diekspor dari aplikasi Daily Task di claude.ai pada 8 Oktober 2026.

ISI
- dailytask-export.json : SEMUA data (tim, unit, admin, tugas, komentar, bukti, catatan, link admin).
                          Format JSON biasa, bisa dibaca sistem apa pun.
- proof-photos/         : foto bukti tugas (dirujuk dari proof.photoFile di JSON).
- dailytask.sql         : data yang sama dalam bentuk SQL (PostgreSQL / MySQL / SQLite).
- import-firebase.mjs   : skrip impor otomatis ke Firebase (versi aplikasi HP di folder pwa/ repo GitHub).
- email-map.json        : daftar orang -> email. WAJIB diisi sebelum impor ke Firebase.

PERHATIAN: berisi data pribadi karyawan (dipublikasikan atas keputusan pemilik). Kunci service-account.json JANGAN pernah di-commit.

A. PINDAH KE APLIKASI HP (Firebase)
1. Pasang aplikasi HP dulu sesuai pwa/BACA-DULU.txt di repo (buat proyek Firebase, isi config.js, deploy).
2. Pasang Node.js (https://nodejs.org), lalu di folder ini jalankan:  npm install
3. Buka email-map.json, isi email Google tiap orang, contoh:  "fahru": "fahru@gmail.com"
   Yang dikosongkan akan dilewati (tidak diimpor).
4. Firebase Console > Project settings > Service accounts > Generate new private key.
   Simpan file itu di folder ini dengan nama service-account.json (rahasia, jangan dibagikan).
5. Cek dulu (tidak menulis apa pun):   node import-firebase.mjs
6. Kalau ringkasannya benar, impor:    node import-firebase.mjs --apply
   Aman dijalankan ulang: data yang sama akan ditimpa, bukan digandakan.

B. PINDAH KE SERVER / DATABASE LAIN
- MySQL:      mysql -u USER -p NAMA_DB < dailytask.sql
- PostgreSQL: psql -d NAMA_DB -f dailytask.sql
- SQLite:     sqlite3 dailytask.db < dailytask.sql
Foto bukti: salin folder proof-photos/ ke server; kolom tasks.proof_photo_file berisi nama filenya.

CATATAN
- Waktu (created_at, done_at, dll.) dalam milidetik Unix. Tanggal tugas YYYY-MM-DD, jam HH:MM (WIB).
- Akun claude.ai tidak bisa dipindah. Di sistem baru tiap orang login dengan email masing-masing.
- Kunci enkripsi dan salinan terenkripsi khusus claude.ai tidak ikut karena tidak berguna di sistem lain.
